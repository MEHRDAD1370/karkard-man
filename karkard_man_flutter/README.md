# کارکرد من — Flutter MVP

نسخه شروع کدنویسی اپلیکیشن شخصی حضور و غیاب.

- Android 9 / API 28 به بالا
- فارسی و RTL
- ثبت ورود/خروج با یک لمس
- جلوگیری از ثبت تکراری
- ویرایش ورود و خروج
- محاسبه حضور، تأخیر، تعجیل و اضافه‌کاری
- جمع کل ساعات حضور در شرکت
- نرخ سرپرست ۱,۷۶۰,۰۰۰ ریال، مسئول ۱,۷۴۰,۰۰۰ ریال، پرسنل ۱,۷۲۰,۰۰۰ ریال
- ستادی: نرخ دستی
- جمعه و تعطیلات رسمی با همان نرخ ساعتی
- ذخیره آفلاین + همگام‌سازی آنلاین تعطیلات و کش محلی
- بخش درباره برنامه: برنامه نویس: M.R

## اجرا
flutter pub get
flutter run

## ساخت APK
flutter build apk --release

نکته: این خروجی سورس MVP است و قبل از انتشار نهایی باید منبع رسمی تعطیلات، تقویم شمسی ماهانه، مرخصی کامل، snapshot نرخ‌ها، پشتیبان‌گیری و تست روی Android 9 تا نسخه‌های جدید تکمیل شود.
